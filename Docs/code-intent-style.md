# Code Intent 작성 규칙

## 원칙

- 설명 문장은 한국어로 작성
- code, symbol, path, Unreal 용어, tool name은 원문 유지
- 사실, 추정, 미확인을 분리
- 긴 설명보다 짧은 card와 graph link 우선
- 유사 API는 `헷갈리기 쉬운 코드`에 반드시 기록

- `정의 위치`

- `사용하면 안 되는 상황`
- `기본 흐름`
- `이 코드를 호출하는 쪽`
- `이 코드가 호출하는 쪽`

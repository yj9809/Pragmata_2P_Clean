Diana Cleanse Cooldown UI 구조

UI는 gameplay component를 직접 읽지 않는다. 정화 스킬 cooldown 상태는 ViewModel FieldNotify 값에 바인딩한다.

UPragmataHUDViewModel -> bCanUseCleanse / CleanseCooldownProgress

Ready

bCanUseCleanse=true
CleanseCooldownProgress=1.0

Cooldown

bCanUseCleanse=false
0.0 -> 1.0 증가

금지

Widget에서 UDianaCleanseComponent 직접 polling 금지

데이터 흐름

Cooldown bar 방향

GetCleanseCooldownProgress()는 elapsed / max. 사용 직후 0, 완료 시 1.

사용 직후: 0.0

2.5초 경과: 0.5

5초 완료: 1.0

UI 디자이너 계약

ViewModel 항목 타입 UI 사용
bCanUseCleanse
CanUseCleanse()		 bool 정화 스킬 icon enabled/disabled, input 가능 표시. cooldown 중 false
CleanseCooldownProgress
GetCleanseCooldownProgress()		 float 0..1 cooldown progress bar fill. 사용 직후 0.0, 5초 후 1.0

실행 후 상태 변화

IA_Cleanse
quick press 또는 aim+hold/release로 실행 확정
↓
bCanUseCleanse=false
스킬 아이콘 disabled, cooldown bar 0부터 시작
↓
CleanseCooldownProgress
HUD tick에서 0.0 -> 1.0 증가
↓
bCanUseCleanse=true
5초 후 다시 사용 가능

표시 규칙

ready progress 1.0, icon active
cooldown progress fill 증가, icon dim/locked
실행 거부 조건 action lock, hack active, aim mode 조건은 서버 검증 영역. 이 UI bool에는 포함하지 않음
양쪽 player replicated component state -> 각 HUD ViewModel에 같은 값 전달

검증 체크

상황 기대 결과
PIE 시작 bCanUseCleanse=true, CleanseCooldownProgress=1.0
quick cleanse 실행 직후 양쪽 HUD에서 bCanUseCleanse=false, progress 0.0
precise cleanse 실행 직후 quick과 같은 cooldown UI 상태
cooldown 5초 경과 양쪽 HUD에서 bCanUseCleanse=true, progress 1.0

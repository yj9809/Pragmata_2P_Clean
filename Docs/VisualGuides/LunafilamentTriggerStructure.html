Lunafilament UI 검증 흐름

UI는 gameplay 값을 만들지 않는다. 서버의 Hugh stats 값을 받아 표시와 획득 연출만 처리한다.

Gameplay reward source -> AddLunafilament(Amount)

Gameplay source

UPragmataPlayerStatsComponent::Lunafilament

UI-facing signal

UPragmataHUDViewModel::OnLunafilamentGainedForUI(Delta, OldTotal, NewTotal)

호출 흐름

enemy / item / interaction reward source
서버가 검증한 보상 지급 지점
↓
UPragmataPlayerStatsComponent::AddLunafilament(Amount)
서버 authoritative 총액 즉시 증가
↓
OnLunafilamentChanged(NewTotal)
실제 총액 갱신. 초기화/소비/강제 보정용
↓
OnLunafilamentGained(Delta, OldTotal, NewTotal)
획득 연출용 delta 이벤트
↓
UPragmataHUDViewModel::OnLunafilamentGainedForUI
WBP가 구독할 UI-facing broadcast

기대 연출

1 HUD 생성 시 표시 총액은 PragmataHUDViewModel.Lunafilament로 초기화
2 획득 이벤트는 OnLunafilamentGainedForUI로 받고 1초 동안 delta 합산
3 +MergedDelta 표시 후 animation/timer 종료 시 표시 총액을 latest NewTotal로 반영

금지

PragmataHUDViewModel.Lunafilament를 animated count Text에 직접 바인딩하지 않음. 표시용 값은 WBP presentation cache로만 보유.

UI 디자이너 계약

항목 사용 방법
Lunafilament authoritative total. HUD 생성/초기화, 소비/감소 보정에 사용
OnLunafilamentGainedForUI 획득 연출 trigger. Delta를 1초 merge window 안에서 합산
OldTotal 이 이벤트 직전 서버 총액. 첫 gain 기준값과 순서 검증용
NewTotal 이 이벤트 직후 서버 총액. merge/animation 종료 시 표시 총액 commit 대상
GetLunafilamentGainMergeWindowSeconds() 1.0. 추가 획득이 이 시간 안에 들어오면 +N을 합산 표시

검증 체크

입력 기대 결과
OnLunafilamentGainedForUI(50, 0, 50) +50 표시 후 displayed total 50 반영
1초 안에 +20, +30 gain event +50 합산 표시, 최종 displayed total은 latest NewTotal
SpendLunafilament gain event 없이 authoritative total로 즉시 보정
Hugh/Diana 2-player PIE 양쪽 HUD가 같은 최종 총액 표시

지도 오브젝트 상호작용 계약

공통 실행 지점은 아래 함수다. Diana 쪽 코드는 대상 선택과 검증을 담당한다.

Interact_Implementation(AActor* Interactor)

지도 오브젝트

문 열기, 장치 켜기, 퍼즐 시작 같은 실제 반응

Diana

조준 대상 찾기, 거리 확인, 서버 검증

경계

Diana 코드 안에 오브젝트별 반응 로직 없음

호출 흐름

구현 예시

void AMyMapObject::Interact_Implementation(AActor* Interactor)
{
    // 여기에 오브젝트 반응 작성
    // 예: 문 열기, 전원 켜기, 퍼즐 시작
}

클래스는 UPropInteractableInterface를 구현해야 한다.

현재 규칙

대상 어떻게 실행되는가 지도 오브젝트가 구현할 함수
맵 해킹 노드 Diana가 조준하면 자동 실행 Interact_Implementation
아이템 박스 Diana가 조준한 뒤 상호작용 키를 눌러야 실행 Interact_Implementation
적 해킹 Diana가 조준하면 자동 실행 지도 오브젝트 구조와 별도
스캔 표시 화면에 위치와 거리만 표시 오브젝트 반응 실행 없음

한 줄 결론

Interact_Implementation(AActor* Interactor)가 지도 오브젝트의 반응 지점이다. Diana 쪽은 오브젝트 내부 함수를 직접 호출하지 않는다.

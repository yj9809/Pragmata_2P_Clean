Hugh Heal Recovery UI 구조

UI는 heal을 직접 실행하지 않는다. Hugh gameplay state가 ViewModel recovery field를 갱신하고, WBP는 그 값만 바인딩한다.

AHughCharacter -> UPragmataHUDViewModel -> Recovery UI

수량

RecoveryItemCount
남은 heal cartridge 표시

Hold ring

RecoveryHoldProgress
0.0 -> 1.0 circular fill

금지 상태

bCanUseHeal=false
bRecoveryProhibited=true

데이터 흐름

Hold ring 방향

GetHealHoldProgress()는 현재 hold 시간 / 1초 threshold. 버튼을 떼거나 blocker가 생기면 0으로 reset.

0.0

입력 시작 전

0.5

0.5초 hold

1.0

heal 요청 발생

UI 디자이너 계약

ViewModel 항목 타입 UI 사용
RecoveryItemCount
GetRecoveryItemCount()		 int 남은 heal cartridge count. Hugh/Diana HUD 모두 같은 수량 표시
RecoveryHoldProgress
GetRecoveryHoldProgress()		 float 0..1 heal button circular progress fill. local Hugh가 hold 중일 때만 증가
bRecoveryHolding
IsRecoveryHolding()		 bool hold ring 표시/숨김, pulse animation 시작 조건
bCanUseHeal
CanUseHeal()		 bool heal button enabled 상태. 양쪽 HUD가 같은 blocker 상태 표시
bRecoveryProhibited
IsRecoveryProhibited()		 bool 금지 표시 alias. 현재 !bCanUseHeal로 동기화

실행 흐름

IA_Heal Started
local Hugh hold 시작, progress 0부터 증가
↓
RecoveryHoldProgress == 1.0
1초 도달 시 Server_RequestHeal() 요청
↓
CalculateHealAvailability()
서버가 cartridge, HP, death, reload, dash/run, falling/hovering 재검증
↓
ConsumeRepairCartridge()
실제 HP 회복 성공 시 cartridge 1개 차감
↓
OnHealAvailabilityChanged
ViewModel recovery count/prohibited/can-use 갱신

표시 규칙

사용 가능 bCanUseHeal=true, count 1 이상, button active
hold 중 bRecoveryHolding=true, ring이 RecoveryHoldProgress만큼 fill
반복 회복 hold 유지 시 1초마다 server heal 재요청. ring은 계속 full 상태 유지 가능
금지 full HP, cartridge 0, death, reload, dash/run, falling/hovering 중 disabled 표시
reset 입력 해제, cartridge 0, blocker 발생 시 ring progress 0

검증 체크

상황 기대 결과
Hugh damaged, cartridge 1 이상 CanUseHeal=true, recovery button active
Q 또는 Gamepad_FaceButton_Right 1초 hold ring 0에서 1까지 fill, heal 1회 실행, count 1 감소
hold 유지 cartridge가 남아 있고 blocker가 없으면 1초마다 추가 heal
full HP 또는 airborne/dash/run/reload CanUseHeal=false, RecoveryProhibited=true, ring reset
Diana HUD replicated count와 can-use 상태 표시. Hugh local hold progress는 표시하지 않음

Diana Hair Physics 수동 튜닝 가이드

대상 프로젝트: Pragmata_2P · 대상 asset: /Game/Character/Diana/PA_Diana_Hair, /Game/Blueprints/Player/ABP_Diana

현재 자동화 완료 상태

이미 완료된 작업:

  • PA_Diana 복제본 PA_Diana_Hair 생성 및 저장
  • ABP_Diana AnimGraph 끝단에 RigidBody node 추가
  • final FABRIK 출력이 RigidBody를 거쳐 ComponentToLocalSpace로 들어가도록 연결
  • RigidBody.OverridePhysicsAsset = /Game/Character/Diana/PA_Diana_Hair
  • Simulation Space = Component Space
  • Component Linear Acc Scale = X 0, Y 0, Z 1.5

남은 수동 작업은 PA_Diana_Hair 안의 body, collision, constraint tuning이다. 현재 asset은 전용 복제본이지만, hair 전용 body mode와 limit 값은 Physics Asset Editor에서 직접 정리해야 한다.

목표 동작

  • Diana skeletal mesh가 jump 상승할 때 hair chain이 약간 늦게 따라오며 위아래로 흔들림
  • fall/land 후 hair가 1~2회 감쇠 진동 후 안정화
  • head, neck, shoulder 주변에서 hair가 크게 관통하지 않음
  • frame hitch, teleport, respawn 직후 hair가 폭발적으로 튀지 않음
  • SM_Diana 기본 PhysicsAsset slot은 변경하지 않음

대상 hair bone chain

그룹 Bone 권장 역할
Left front hair L_HairChain_00 → L_HairChain_03 → L_HairChain_end root 고정, 중간 simulation, end는 body 없음 또는 terminal body
Right front hair R_HairChain_00 → R_HairChain_03 → R_HairChain_end root 고정, 중간 simulation, end는 body 없음 또는 terminal body
Back hair L_BackHairChain_00..02/end, C_BackHairChain_00..02/end, R_BackHairChain_00..02/end root 고정, 중간 simulation, end는 body 없음 또는 terminal body

현재 확인된 body coverage는 일부 bone에만 존재. 화면/asset 문자열 기준 body가 있는 것으로 보이는 bone:

  • L_BackHairChain_00, L_BackHairChain_02, L_HairChain_01
  • C_BackHairChain_01
  • R_BackHairChain_01, R_HairChain_01

hair physics용으로는 아래 목록을 Skeleton Tree에서 모두 확인하고, body가 없는 bone에 body를 추가한다.

작업 Bone 목록 권장 shape
Root body 생성 후 Kinematic L_HairChain_00, R_HairChain_00, L_BackHairChain_00, C_BackHairChain_00, R_BackHairChain_00 Capsule 또는 Sphere, scalp 근처에 작게
Simulated body 생성 L_HairChain_01, L_HairChain_02, L_HairChain_03, R_HairChain_01, R_HairChain_02, R_HairChain_03 Capsule, chain 방향으로 길게
Back hair simulated body 생성 L_BackHairChain_01, L_BackHairChain_02, C_BackHairChain_01, C_BackHairChain_02, R_BackHairChain_01, R_BackHairChain_02 Capsule, 머리 뒤쪽 흐름에 맞춤
End body는 기본 제외 L_HairChain_end, R_HairChain_end, L_BackHairChain_end, C_BackHairChain_end, R_BackHairChain_end body 없음. 필요할 때만 매우 작은 Sphere

새 PhysicsAsset부터 만드는 방법

기존 PA_Diana_Hair를 계속 쓰는 것이 기본. asset이 망가졌거나 처음부터 다시 만들 때만 사용.

  1. Content Browser에서 Content/Character/Diana/SM_Diana 선택
  2. 우클릭 → Create 또는 Physics 관련 메뉴 → Physics Asset 선택
  3. 생성 창이 뜨면 asset 이름을 PA_Diana_Hair_Rebuild처럼 임시 이름으로 생성
  4. 자동 생성 설정은 전체 body가 너무 많이 생기기 쉬우므로, hair만 필요하면 생성 후 불필요 body 삭제 또는 빈 asset에 수동 추가
  5. 기존 ABP_Diana의 RigidBody.Override Physics Asset은 새 asset으로 바꾸기 전까지 PA_Diana_Hair를 계속 가리킴

Epic 문서 기준 PhysicsAsset은 Content Drawer에서 Skeletal Mesh를 선택해 만들 수 있고, 처음 열 때 body/constraint 생성 옵션 창이 표시될 수 있다. 이 프로젝트에서는 원본 SM_Diana 기본 PhysicsAsset slot을 바꾸지 않고 AnimGraph RigidBody override만 사용한다.

Physics Asset Editor 열기

  1. Unreal Editor에서 Content Browser 열기
  2. Content/Character/Diana로 이동
  3. PA_Diana_Hair 더블 클릭
  4. 상단 toolbar에서 Skeleton Tree, Details, Profiles panel 표시 확인
  5. 우측 viewport에서 Diana head와 hair chain body가 보이는지 확인
  6. Skeleton Tree의 Options dropdown 열기
  7. Show Bones와 Show Primitives를 켜서 body가 없는 hair bone까지 보이게 설정

PA_Diana 원본은 열어서 수정하지 않는다. 잘못 열었으면 닫고 PA_Diana_Hair만 수정한다.

Hair body 생성 방법

권장: bone별 Add/Replace Body

  1. Skeleton Tree에서 body가 없는 hair bone 선택
  2. bone 우클릭 → Add/Replace Body 선택
  3. 기본 Capsule body 생성 확인
  4. 더 얇은 모양이 필요하면 body 우클릭 → Add Shape → Capsule, Sphere, Box 중 선택
  5. 기본 capsule이 불필요하면 해당 primitive만 선택 후 Delete
  6. viewport에서 W/E/R 또는 toolbar의 translate/rotate/scale tool로 hair mesh에 맞춤

Epic 문서 기준 body가 없는 bone은 우클릭 Add Shape만으로도 새 Physics Body와 shape를 같이 만들 수 있다. 이미 body가 있는 bone에서 Add/Replace Body를 누르면 기존 body가 교체되므로 주의.

선택 bone batch generate

  1. Skeleton Tree에서 Ctrl 또는 Shift로 hair bones만 다중 선택
  2. *_end bone은 기본적으로 선택하지 않음
  3. Tools tab 열기
  4. body generation 영역에서 selected bones 또는 selected bodies 대상 generate/regenerate 옵션 확인
  5. 가능하면 Create body for all bones류 옵션은 끄고, 선택한 hair bones만 대상으로 실행
  6. 생성 후 body가 너무 큰 bone은 바로 scale 축소
  7. hair 외 body가 생기면 삭제

Generate All Bodies는 전체 skeleton에 body를 만들 수 있다. Diana 전체 body가 대량 생성되면 simulation 비용과 충돌 문제가 커지므로, hair chain만 선택한 상태에서 실행하거나 bone별 수동 생성 사용.

Body 정리 순서

1. Hair root body 고정

  1. Skeleton Tree에서 아래 root body 선택:
    • L_HairChain_00, R_HairChain_00
    • L_BackHairChain_00, C_BackHairChain_00, R_BackHairChain_00
  2. Details에서 Physics Type을 Kinematic으로 설정
  3. body shape가 scalp 근처에서 과하게 크면 scale을 줄여 hair root만 잡도록 조정

2. Hair middle body simulation

  1. 중간 chain body 선택:
    • L_HairChain_01, L_HairChain_02, L_HairChain_03
    • R_HairChain_01, R_HairChain_02, R_HairChain_03
    • L/C/R_BackHairChain_01, L/C/R_BackHairChain_02
  2. Physics Type을 Simulated로 설정
  3. body shape는 hair strand 두께보다 조금 크게, 서로 겹치지 않게 조정
  4. front hair는 얼굴 충돌을 피하기 위해 body를 hair mesh 안쪽보다 약간 바깥쪽으로 배치

3. End bone 처리

  1. *_end body가 있으면 먼저 삭제를 고려
  2. 끝부분 흔들림이 너무 딱딱하면 아주 작은 terminal body 유지
  3. terminal body 유지 시 mass를 가장 작게 두고 collision은 adjacent hair와 꺼짐 상태 확인

초기 tuning 값

항목 Root 근처 Tip 근처 비고
Mass 0.3 ~ 0.5 0.05 ~ 0.15 끝으로 갈수록 가볍게 시작
Linear Damping 3 ~ 6 3 ~ 6 떨림이 있으면 먼저 증가
Angular Damping 3 ~ 6 3 ~ 6 회전 폭발 억제용
Constraint Swing Limit 10 ~ 20 deg 20 ~ 35 deg 끝으로 갈수록 조금 넓게
Constraint Twist Limit 5 ~ 15 deg 10 ~ 20 deg roll 꼬임이 보이면 축소

처음부터 크게 흔들리게 만들지 말고 안정적인 작은 흔들림부터 만든다. 반응 부족은 나중에 ComponentLinearAccScale이나 damping으로 키우는 편이 안전하다.

Collision 설정

켜둘 충돌

  • hair body ↔ Head
  • hair body ↔ Neck
  • back hair ↔ Spine_2
  • 필요 시 shoulder 주변 kinematic body

꺼둘 충돌

  • 같은 chain의 인접 hair body끼리 충돌
  • left/right hair끼리 불필요한 상호 충돌
  • terminal body와 직전 body의 충돌
  • 작은 body가 head 내부에서 시작하는 충돌
  1. Physics Asset Editor에서 hair body 두 개 선택
  2. context menu 또는 collision tool에서 Disable Collision 적용
  3. head/neck/body collision은 켠 상태로 둠
  4. Simulate에서 hair가 서로 밀어내며 튀지 않는지 확인

Constraint 설정

  1. 각 hair chain의 parent-child constraint 선택
  2. Angular Swing 1 Motion, Angular Swing 2 Motion을 Limited로 설정
  3. Angular Twist Motion도 Limited로 설정
  4. root 근처 constraint는 작은 각도, tip 근처 constraint는 조금 큰 각도 적용
  5. Projection 또는 stabilization 관련 옵션이 있으면 과한 늘어짐 방지용으로 낮은 값부터 적용

constraint cone이 hair가 자연스럽게 흔들릴 방향을 향해야 한다. front hair가 얼굴 쪽으로만 접히면 constraint frame을 조정하거나 swing limit 축을 줄인다.

ABP_Diana 확인

  1. Content/Blueprints/Player/ABP_Diana 열기
  2. AnimGraph로 이동
  3. 끝단 연결 확인:
    • 기존 FABRIK chain output → RigidBody
    • RigidBody → ComponentToLocalSpace
    • ComponentToLocalSpace → Output Pose
  4. RigidBody node 선택
  5. Override Physics Asset이 PA_Diana_Hair인지 확인
  6. Simulation Space가 Component Space인지 확인
  7. Component Linear Acc Scale의 Z 값이 1.5 근처인지 확인
  8. Compile 후 Save

PIE

  • Diana avatar가 붙은 상태로 Hugh jump/fall 동작 확인

문제별 tuning 순서

증상 먼저 확인 다음 조정
hair가 떨림 adjacent collision off, body overlap 제거 linear/angular damping 증가, mass 차이 완화
hair 반응 부족 RigidBody.ComponentLinearAccScale.Z 값 Z scale 증가, damping 감소, swing limit 확대
얼굴 관통 Head/Neck kinematic collision body 크기 front hair swing limit 축소, body 위치 바깥쪽 보정
착지 때 폭발 constraint frame, collision overlap, terminal body damping 증가, terminal body 제거, acceleration scale 감소

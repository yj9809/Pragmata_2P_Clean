튜토리얼 트리거 작업 가이드

맵 작업자가 위치별 튜토리얼을 만들고 배치하는 방법

핵심 구조 
DA_Tutorial_이름        제목 · 이미지 · 설명 · 키 안내 · 표시 대상
        ↓
BP_TutorialTrigger_이름 발동 역할 · Box 크기 · Tutorial Id · 종료 방식
        ↓
Map 배치                위치 · 회전 · 인스턴스 설정

튜토리얼 하나마다 DataAsset 1개와 Trigger Blueprint 1개를 만드는 방식이 기본입니다.

1. 준비된 자산

자산경로용도
BP_TutorialTriggerBase/Game/Blueprints/Props/Tutorial/모든 공간 튜토리얼의 부모
BP_TutorialTrigger_WeaponsUse/Game/Blueprints/Props/Tutorial/무기 사용 예제
DA_Tutorial_WeaponsUse/Game/UI/Data/내용이 입력된 DataAsset 예제
Level Blueprint에 overlap 또는 popup 로직을 복사하지 마세요. 공통 동작은 C++ base가 처리합니다.

2. DataAsset 만들기

  1. Content Browser에서 우클릭 → Miscellaneous → Data Asset을 선택합니다.
  2. 클래스로 TutorialStepData를 선택합니다.
  3. DA_Tutorial_내용 형식으로 이름을 지정합니다.
  4. 아래 값을 입력하고 저장합니다.
항목의미
Step Title팝업 제목
Preview Image표시 이미지
Description Text플레이 설명
Key Bindings행동 이름과 RichText 아이콘 row
Target Role팝업을 볼 역할. None은 양쪽

3. Trigger Blueprint 만들기

  1. BP_TutorialTriggerBase를 우클릭합니다.
  2. Create Child Blueprint Class를 선택합니다.
  3. BP_TutorialTrigger_내용 형식으로 이름을 지정합니다.
  4. child를 열고 Class Defaults를 선택합니다.
  5. Pragmata | Tutorial Trigger 설정을 입력합니다.
  6. Compile 후 Save합니다.
설정설명권장값
Tutorial Step표시할 DataAsset방금 만든 DA_Tutorial_*
Tutorial Id영구 1회 표시 SaveGame 키Weapon.FirstAcquired처럼 고유한 이름
Activation Role누가 Box에 들어와야 발동하는지공용 None, 역할 전용은 해당 역할
Enabled트리거 활성 여부true
Dismiss Policy팝업 종료 방식보통 Until Replaced
Display Duration SecondsTimed 표시 시간필요한 초
역할 구분: Activation Role은 누가 밟는지, DataAsset의 Target Role은 누가 팝업을 보는지 결정합니다.
목적Activation RoleTarget Role
누가 들어가도 양쪽 표시NoneNone
Hugh 전용HughHugh
Diana 전용DianaDiana
누가 들어가도 Diana에게만 표시NoneDiana

4. Box와 Map 배치

  1. Components에서 TriggerBox를 선택합니다.
  2. Box Extent를 실제 이동 경로보다 약간 넓게 설정합니다. 기본값은 200 × 200 × 100입니다.
  3. 목적별 child Blueprint를 맵으로 드래그합니다.
  4. 위치, 회전, Box 범위를 조정합니다.
  5. 필요하면 배치 인스턴스 Details에서 Tutorial Step을 override합니다.
  6. 맵을 저장합니다.

5. 종료 방식

정책동작
Until Replaced다음 튜토리얼 또는 명시 hide까지 유지
Timed설정한 시간 뒤 자동 종료

이전 Timed 트리거의 timer는 나중에 표시된 최신 튜토리얼을 닫지 않습니다.

6. 공간 Trigger가 아닌 호출

무기 획득, 전투, 퍼즐처럼 C++ 또는 Blueprint 이벤트에서 직접 표시하는 방법은 튜토리얼 단일 함수 사용 가이드를 참고합니다.

7. 테스트 체크리스트

  • Blueprint Compile에 warning/error가 없다.
  • 제목, 이미지, 설명이 정확히 표시된다.
  • 올바른 역할이 들어왔을 때만 발동한다.
  • 잘못된 역할 진입은 영구 표시 이력을 소비하지 않는다.
  • 같은 Tutorial Id는 반복 진입과 게임 재실행 뒤에도 다시 표시되지 않는다.
  • Enabled=false에서는 표시되지 않는다.
  • Timed는 설정 시간 후 닫힌다.
  • Hugh host와 Diana host 양쪽 구성에서 결과가 같다.

8. Cook 및 패키징

  • 맵에 배치한 child와 hard DataAsset은 맵 dependency로 cook됩니다.
  • 새 Preview Image는 soft reference이므로 /Game/CookLabels/PAL_CoreRuntime의 Explicit Assets에도 추가합니다.
  • 맵에 배치하지 않고 동적으로 생성하는 child/DataAsset도 PAL에 추가합니다.
  • 넓은 폴더 전체를 Always Cook으로 추가하지 않습니다.

9. 문제 해결

팝업이 표시되지 않음

  • Enabled와 Tutorial Step을 확인합니다.
  • Activation Role과 실제 진입 역할을 비교합니다.
  • DataAsset의 Target Role을 확인합니다.
  • TriggerBox가 Pawn 경로와 실제로 겹치는지 확인합니다.

PIE에서는 보이지만 패키지에서 이미지가 없음

Preview texture가 PAL_CoreRuntime에 포함됐는지 확인합니다.

Cleanse 획득 튜토리얼은 기존 CleanseSkillAcquisitionProp 경로를 유지합니다. 별도 기획 없이 공간 trigger로 교체하지 마세요.

10. 작업 완료 전달 항목

  • 생성한 DataAsset과 child Blueprint 목록
  • 배치한 Map과 위치
  • 각 trigger의 Activation Role / Target Role
  • 새 Preview Image의 PAL 등록 여부
  • Standalone 및 2-player PIE 확인 결과
